## Description
The user insert a sentence, the program validates if the user insert the sentences or not, if the user insert the sentence, then the program will display total word count and total character count including spaces
## How to Run
1. Open the project in PyCharm
2. Ensure Python 3.12 is selected.
3. open CSC649_Setup_2024653626 project file 
4. run main.py 
## limitation
Accepts meaningless inputs like 12345, ..., or @#$%^ are treated as valid sentences.
